# Fonts

Bundled so every machine renders pages with exactly the same fonts. Licensed under the
SIL Open Font License 1.1 (see [OFL.txt](OFL.txt), [OFL-NotoSansMath.txt](OFL-NotoSansMath.txt)
and [OFL-NotoSansSymbols2.txt](OFL-NotoSansSymbols2.txt)).

Noto Sans Math and Noto Sans Symbols 2 are fallbacks for symbols the text fonts lack
(for example ≥ ≤ ∼ → ■).
